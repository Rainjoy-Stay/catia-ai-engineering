# STP 管路语义重建独立验收

全模型有限截面入口为 tools/review_full_finite_sections.py。当前原始 STEP 中 1965 条共享边连接全部完成联合边界检查，未形成完整目标圆周；修剪覆盖采样明确保留未运行，而不是写为无覆盖。18 项相关验收通过。这不代表未识别零件不是管路，也不转移到 CATIA 重导出几何或修改原 23 项干涉裁决。

全模型外形入口为 tools/scan_full_step_exteriors.py，直接扫描原始 STEP 成功转入 OCCT 的全部 Solid，保存每个实体的完整 Face 描述。识别不依赖内孔，原始文件与 CATIA 重导出证据严格分别标注；Body 对应不从遍历序号推断。外形候选和支撑相切线索保留 BREP 供后续有限范围复核，不能由相切数量推断工程管路数量。

碎分环面联合验证要求同支撑圆心、轴线和两个半径，保留原 Face 身份。共享圆弧必须构成闭合完整截面；使用三处圆弧位置和 24 个截面方向在真实修剪面中验证采样覆盖。14 项相切、连接图、有限截面及四片环面联合验收通过。四片完整直弯组合可恢复局部候选，缺片拒绝；当前导出缓存联合复核仍为零局部完整截面候选。采样通过不代表全局修剪覆盖或工程管路已确认。

有限直弯连接检查使用实际共享 Edge，要求其形成位于支撑相切点、半径等于截面半径的完整圆周，并检查环面截面参数包络为完整一圈。UV 包络不是完整修剪覆盖证明，通过仅形成局部候选。12 项有限连接与图验收通过；当前导出缓存 32 条共享边连接均未成为完整截面局部候选，不重建工程中心线。

外形识别已支持无内孔的直线圆柱体及小于 180° 的圆弧环面体。弯曲外形须通过端面位于中心线圆、端法向与切线吻合、外表面积转角与端点夹角一致、截面积与材料体积一致等检查；局部圆角及混合管件保持未确定。外形结果不提供壁厚或已确认开口，ports 为空，工程用途和弯曲半径合规性仍待评估。相关外形及管路回归 34 项通过。

几何来源与空腔术语：原始 STEP 实体缓存和 CATIA 重导出 STEP 必须分开验证。用户提示重导出 STP 没有空腔；不得将原始缓存结果移用于导出模型。测试圆柱与某个单实体不相交只证明局部几何空区域，不证明设计空腔、流道或全装配通道；相关结果明确保留 design_cavity_confirmed=false 和 fluid_channel_confirmed=false。

v0.3 增加直管圆柱壁面碎分归组。全部 Face 证据必须完整、唯一且精确有效；同组的所有圆柱必须具有相同支撑轴线和半径。保留每组原始 Face ID，不修改或合并原几何。除体积及端口验证外，内外壁的面积总和各自必须符合完整圆柱壁面积，防止将缺片或覆盖不足的面组认作完整管体。单半径碎分实心柱仍未确定，不能误当成内外壁。

端口内边界支持多段同圆圆弧：要求闭合 wire、所有圆弧同心同半径同轴，参数跨度之和为完整一圈。仍不支持碎分端面与碎分环面。真实 OCCT 闭合面碎分验收、缺片、偏轴及面积不足反例与现有几何和干涉回归共 58 项通过。

v0.2 新增小于 180° 的圆弧空心弯管候选。要求两个同心、同轴且中心线半径相同的环面，两个环形端面位于中心线圆上，端法向与圆弧切线吻合，壁体积、环面面积和端点夹角共同验证弧长及转角。输出中心线弯曲半径、转角、弧长、壁厚和端口。未提供设计限值，弯曲半径合规性保持 NOT_EVALUATED。

端口连接候选要求端中心重合、向外方向相反、内外径均吻合。多个候选争用同一端口时标记 ambiguous。所有连接 verified=false、状态 NOT_EVALUATED；不得直接写入干涉过滤层的已验证接口证据。即使端口吻合，其他区域仍可能穿模，仍需独立检查全部相交范围和设计意图。

v0.2 精确几何验收新增 45° 与 90° 弯管、旋转和平移、实心弯体及闭环反例、弯管 STEP 往返、弯管与直管连接、直径和间隙反例、重合重复体及竞争端口。与直管及干涉过滤层共 36 项测试通过。尚未接入发动机正式报告，不修改原 23 项待评估结论。

v0.1 只识别有效单实体、完整且唯一的精确 Face 证据所支持的直线空心圆管几何候选。要求两个同轴圆柱、两个环形端面、同轴且同半径的通孔端界，以及符合尺寸的端面积和公共管壁体积。

返回外半径、内半径、壁厚、端中心、轴方向和长度；保留 Solid 和 Face 标识。所有结果为 NOT_EVALUATED，engineering_pipe_confirmed 为 false。套筒等几何相同零件仍可能成为候选，需设计或装配语义才能确认用途。

本阶段不确认设计接口，不消除重叠，不检查工程弯曲半径合规性。180° 及更大转角、分割解析面、BSpline、带法兰管段及复杂支路尚未支持，应保留未确定。不得把未支持的几何当作非管路。

独立验收覆盖标准直管、任意空间轴向、实心圆柱、穿孔方块、盲孔、偏心孔、STEP 写入读取往返和重复 Face 证据。后续依次增加弯管几何与端口连接候选；接入发动机模型前继续保留过滤层的待评估状态和来源完整性要求。
