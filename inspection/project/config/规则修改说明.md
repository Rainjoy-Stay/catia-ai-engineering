# Description of changes to the current inspection rules

The actual entry into force document is a `rules-active.json` from the same directory. Copy a left-over file before the change; change the `ruleset_id` after the change in the rules will place the complete rule at the top of the text.

| Contents to modify|JSON Fields| Units/example|
|---|---|---|
| Normal minimum space|`routing.minimum_general_clearance_mm`| mm; 100 for 10 cm|
| Minimum spacing of the hot zone|`routing.minimum_hot_zone_clearance_mm`| mm|
| Curve Radius Rule Type|`routing.bend_radius_mode`|`absolute_mm` or `ratio_r_over_d`|
| Absolute minimum bend radius|`routing.minimum_bend_radius_mm`| mm; 100 for 10 cm|
| Relative curved R/D radius|`routing.minimum_bend_radius_ratio_r_over_d`|No schematic; 0.25 for a quarter of D|
|DMU Scan Space|`dmu_clash.clearance_mm`| mm|
|Whether or not contact failed|`dmu_clash.contact_is_failure`| True or false|
| Clearly allowed contact is correct.|`exemptions.allowed_contact_pairs`|Accurate component name paired|
| Take over the axle centre deviation.|`opening_interface.coaxial_tolerance_mm`| mm;exceeding i.e. FAIL|
| Take over the axle-line angle.|`opening_interface.angle_tolerance_deg`| degrees;exceeding i.e. FAIL|
| Minimum aperture/maximum diameter gap|`opening_interface.radial_clearance_min_mm/max_mm`| mm|
| Take over the axle and pass through.|`opening_interface.axial_tolerance_mm`| mm|
| Open open candidates for the rough screening range|`opening_interface.candidate_*`| Just control the candidate's recall, not the PASS.|
| Multiple candidate differentials|`opening_interface.ambiguity_score_delta`|No scalding;close candidate for REVIEW|
| Rule clearance status|`routing.threshold_status`| Formal rules to fill `APPROVED`, not approved to fill `ASSUMED_PENDING_APPROVAL`|
| Standard sources|`source` and `routing.standard_reference`| Document number, version, date, approver|

When the user says, "Turn the radius to 10 cm": Set mode to `absolute_mm` and set `minimum_bend_radius_mm` to 100.

The user says, "When the bend radius is changed to a quarter of D", setting mode `ratio_r_over_d` and setting `minimum_bend_radius_ratio_r_over_d` 0.25.

When a user provides a standard document, read the scope of application, unit, threshold, exception, version and approval of the document, generate candidate rules and show them to the user; the disagreement cannot be filled in. User confirmation is not given until the current rules are in force. The rules for this inspection must also generate a temporary copy with a new ruleset_id and pass through `--rules`, which cannot cover the long-term rules quietly.

Agent changes the rules by calling `runtime\python.exe scripts\update_rules.py` as a matter of priority, and the required fields, values and approval status is verified by the script. For example:

```text
runtime\python.exe scripts\update_rules.py --bend-radius-mm 100 --ruleset-id 项目A-R100-v1
runtime\python.exe scripts\update_rules.py --bend-radius-ratio 0.25 --for-this-run --ruleset-id 本次-R025-v1
runtime\python.exe scripts\update_rules.py --opening-coaxial-tolerance-mm 0.5 --opening-angle-tolerance-deg 1 --opening-radial-clearance-min-mm 0 --opening-radial-clearance-max-mm 2 --opening-axial-tolerance-mm 0.1 --for-this-run --ruleset-id 本次-开孔接口-v1
```

The second command returns the name of a `rules-run-*.json` file. Agent calls `catia_check_assembly` and transfers the file name to `rules_file`; the fixed entry can execute `一键检查当前模型.cmd --rules project\config\rules-run-*.json`. Do not manually edit the created history check JSON.
