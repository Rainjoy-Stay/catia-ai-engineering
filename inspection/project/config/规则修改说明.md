# 当前检查规则修改说明

实际生效文件是同目录的`rules-active.json`。修改前复制一份留档；规则变更后修改`ruleset_id`，报告会把完整规则放在正文最前面。

|要修改的内容|JSON字段|单位/示例|
|---|---|---|
|普通最小间距|`routing.minimum_general_clearance_mm`|毫米；100表示10厘米|
|热区最小间距|`routing.minimum_hot_zone_clearance_mm`|毫米|
|弯曲半径规则类型|`routing.bend_radius_mode`|`absolute_mm`或`ratio_r_over_d`|
|绝对最小弯曲半径|`routing.minimum_bend_radius_mm`|毫米；100表示10厘米|
|相对弯曲半径R/D|`routing.minimum_bend_radius_ratio_r_over_d`|无量纲；0.25表示四分之一D|
|DMU扫描间距|`dmu_clash.clearance_mm`|毫米|
|接触是否失败|`dmu_clash.contact_is_failure`|true或false|
|明确允许的接触对|`exemptions.allowed_contact_pairs`|精确组件名成对填写|
|接管轴线中心偏差|`opening_interface.coaxial_tolerance_mm`|毫米；超出即FAIL|
|接管轴线夹角|`opening_interface.angle_tolerance_deg`|度；超出即FAIL|
|孔径最小/最大径向间隙|`opening_interface.radial_clearance_min_mm/max_mm`|毫米|
|接管轴向贯穿容差|`opening_interface.axial_tolerance_mm`|毫米|
|开孔候选粗筛范围|`opening_interface.candidate_*`|只控制候选召回，不直接判PASS|
|多候选歧义分差|`opening_interface.ambiguity_score_delta`|无量纲；相近候选进入REVIEW|
|规则审批状态|`routing.threshold_status`|正式规则填`APPROVED`，未审批填`ASSUMED_PENDING_APPROVAL`|
|标准来源|`source`和`routing.standard_reference`|文件编号、版本、日期、批准人|

用户说“弯曲半径改成10cm”时：设置模式为`absolute_mm`，设置`minimum_bend_radius_mm`为100。

用户说“弯曲半径改为四分之一D”时：设置模式为`ratio_r_over_d`，设置`minimum_bend_radius_ratio_r_over_d`为0.25。

用户提供标准文件时：先读取文件中的适用范围、单位、阈值、例外、版本和审批信息，生成候选规则并向用户展示；歧义项不得自行补齐。用户确认后才写入当前生效规则。只针对本次检查的规则也必须生成带新ruleset_id的临时副本，并通过`--rules`传入，不能悄悄覆盖长期规则。

Agent修改规则时优先调用`runtime\python.exe scripts\update_rules.py`，由脚本统一验证必填字段、数值和审批状态。例如：

```text
runtime\python.exe scripts\update_rules.py --bend-radius-mm 100 --ruleset-id 项目A-R100-v1
runtime\python.exe scripts\update_rules.py --bend-radius-ratio 0.25 --for-this-run --ruleset-id 本次-R025-v1
runtime\python.exe scripts\update_rules.py --opening-coaxial-tolerance-mm 0.5 --opening-angle-tolerance-deg 1 --opening-radial-clearance-min-mm 0 --opening-radial-clearance-max-mm 2 --opening-axial-tolerance-mm 0.1 --for-this-run --ruleset-id 本次-开孔接口-v1
```

第二条命令会返回一个`rules-run-*.json`文件名。Agent调用`catia_check_assembly`时把该文件名传入`rules_file`；固定入口可执行`一键检查当前模型.cmd --rules project\config\rules-run-*.json`。不要手工编辑已经生成的历史检查JSON。
