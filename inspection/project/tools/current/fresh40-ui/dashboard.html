CATIA V5 鼠标操作与快捷键（点击展开）

中键＝按下滚轮，不是滚动滚轮。操作适用于主视窗与并行小窗。

  • 平移：按住中键，拖动鼠标。
  • 旋转：先按住中键，再按住左键或右键，一起拖动。模型采用三维轨迹球旋转，视窗中央拖动翻转，靠边拖动可绕视线滚转。也可先按住中键，再按 Ctrl。
  • 缩放：保持中键按住，按一下左键或右键后松开该键，再上下拖动；上移放大，下移缩小。旋转时松开侧键也进入缩放。
  • 结束／重置：松开中键。下一次按住中键从平移开始。
  • 旋转中心：在模型表面中键单击设置中心；从模型表面开始旋转也会选取该点为中心，保持画面位置。
  • 选择：主视窗左键点击零件；Ctrl＋左键追加选择。也可点击名称清单或结果列表。
  • 便捷扩展：滚动滚轮缩放，双击聚焦当前所选，Esc 清除选择，Ctrl＋Home 适配全模型；工具栏提供轴测、正视、俯视与全屏。

手动中键操作会暂停主视窗的跟随与自动旋转，避免抢视角。“仅显示所选”优先于半透明；关闭半透明或清除选择恢复全不透明。

参考：Dassault 导航文档 · CATIA V5 兼容导航说明。便捷扩展不是 CATIA 原生快捷键的完整复刻。
