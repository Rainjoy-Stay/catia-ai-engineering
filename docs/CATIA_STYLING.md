# CATIA V5 自由曲面造型原型

使用 `tools/catia_styling.py` 生成对称盖板。造型意图由对话助手转成参数，再由 CATIA GSD 创建坐标点、开放样条、直线边界和多截面曲面。原型使用合成矩形边界，单位为毫米。

## 从造型意图到曲面

1. 输入盖板长度和宽度。未指定时，示例使用 300 × 180 mm。
2. 将“中部更饱满”转换为增大 `--crown`，它控制中心截面的峰值高度。将“肩部撑起来一些”转换为增大 `--shoulder`，它控制横截面靠外侧的饱满程度，保持中心高度和边界点不变。该参数范围为 0 至 1，默认 0.45。
3. 给用户说明采用的数值。用同一长宽、不同造型参数新建候选件，方便比较。遇到明确折线、不对称或指定现有零件边界时，当前模板无法表达该要求。

在项目根目录用 PowerShell 运行。第一次省略 `--build` 可输出点坐标和建模操作计划，适合无 CATIA 环境预览。

```powershell
$python = '.\release_build\CATIA_Offline_20261012\runtime\python.exe'
& $python -X utf8 .\tools\catia_styling.py --length 300 --width 180 --crown 22 --shoulder 0.65
& $python -X utf8 .\tools\catia_styling.py --length 300 --width 180 --crown 22 --shoulder 0.65 --build
```

实机建模需要可用的 CATIA V5 会话、GSD 能力和全模式 CATIA MCP。可用 `--mcp-root` 指定另一个同布局的离线运行目录。执行时新建未保存的 CATPart，生成的曲面位于 `CAS_Panel/Panel_Surface`。在建模期间保持该文档激活。若建模中途失败，错误会指明可供诊断的未保存文档。脚本在成功后也保留未保存状态。

## CATIA 内的验收

- 确认几何图形集包含 25 个坐标点、5 条截面、2 条导引边和 1 张多截面曲面，并确认零件可更新。
- 编辑中心截面的内部点高度，再更新。检查样条和多截面曲面是否跟随更新，以及四周边界是否仍然贴合设计边界。
- 比较两版曲面的反射线或斑马纹，检查肩部高光和曲率过渡。几何更新成功只证明特征树可解算。边界偏差、曲率质量、工程接口和 Class‑A 放行须单独验收。
